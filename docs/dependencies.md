# Dependency register

This register covers every runtime entry in the root `composer.json` `require` object; `require-dev` is intentionally excluded. Version-floor rationale was checked against `CHANGELOG.md`, `UPGRADING.md`, and the commits that introduced each constraint. Where those sources do not record why a floor was chosen, the rationale says `da verificare`.
